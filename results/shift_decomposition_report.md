## 1. 前提：このモデルの構造

- 入力は 4 シーケンス（T1 / T2 / FLAIR / T1c）の腫瘍最大断面 ±1 スライス。出力は IDH 変異の確率とその確信度
- **late fusion**：6 つの分類器（T1 / T2 / FLAIR / T1c の各 ViT ＋ 4 シーケンス連結の unified ViT ＋ 年齢・性別の tabular MLP）が独立に evidence を出し、最後に足し合わせる。**融合後の単一表現は存在しない**
- 各画像分類器は「384 次元の CLS 特徴 → `Linear(384→2)` → softplus」。出力 2 要素は `e1`（変異側の証拠）と `e0`（野生型側の証拠）
- 融合は `α = Σe1 + 1`, `β = Σe0 + 1` の Beta 分布。予測確率 `p̂ = α/(α+β)`、確信度 `S = α+β`（大きいほど自信あり）
- 設計思想は **AUC ではなく頑健性**：情報が少ないときに事後分布が広がることを要件としている

評価は施設 leave-one-site-out（LOSO）が主。3 施設（UCSF 501 / UTSW 619 / UPenn 515、変異率 18%）。

## 2. 問い

> ドメインシフト（施設・装置が変わること）は、特徴空間の**どこ**に入っているのか。

これは「§2 の打ち手（エンコーダ側の介入：輝度のアフィン不変な拡張、関係特徴の明示化）にどれだけ投資すべきか」を決めるために必要でした。加えて、以前の解析で観測された **「vendor を変えると T1/T2/FLAIR の evidence が落ち、T1c は保たれる」** という現象の、表現空間での正体を知りたかった。

## 3. 方法

### 3.1 分解

エンコーダ $i$ ごとに、inner-val（訓練施設の held-out）と test（シフト先）の平均 CLS 特徴の差

$$\Delta = \overline{f_{\text{test}}} - \overline{f_{\text{val}}} \in \mathbb{R}^{384}$$

を取る。ヘッドの重み行 $W_1$（e1 側）、$W_0$（e0 側）が張る **2 次元の機能的部分空間**に射影する：

| 記号 | 定義 | 意味 |
|---|---|---|
| $u_p$ | $(W_1-W_0)/\lVert W_1-W_0\rVert$ | **判別方向**。動くと判断の物差しのゼロ点（criterion）がずれ、全症例の $\hat p$ が一律に上下する |
| $u_s$ | $\mathrm{orth}(W_1+W_0; u_p)$ を正規化 | **確信方向**。動くと evidence 総量 $S$ が増減する |
| $\Delta_p = \langle\Delta,u_p\rangle$ | | criterion シフト |
| $\Delta_s = \langle\Delta,u_s\rangle$ | | evidence 総量シフト |
| $\Delta_{\text{null}}$ | $\lVert\Delta - \Delta_p u_p - \Delta_s u_s\rVert$ | **このヘッドから機能的に不可視な移動**（384 − 2 = 382 次元ぶん） |

**重要**：384 次元では直交残差のノルムは自明に大きく出る。生のノルムでは何も判定できないので、すべて効果量に変換した：

- $d_p = \Delta_p/\sigma_p$、$d_s = \Delta_s/\sigma_s$（$\sigma$ は **val 特徴のその方向への射影の標準偏差**）。単位は「val 内ばらつきの何個分か」
- $\Delta_{\text{null}}$ は **val を無作為に半分ずつに割って計算した null Δ の残差ノルム**（ブートストラップ 100 回）を雑音床とし、その何倍かで報告。半分割は実際の Δ より標本が小さく保守的なので、標本サイズを揃えた補正版（`floor_match` = 0.58〜0.67）も併記
- $d_p, d_s$ の雑音の目安は解析的標準誤差 $\sqrt{1/n_{\text{val}} + 1/n_{\text{test}}}$（LOSO 0.08、field/vendor 0.13）

### 3.2 機能への翻訳

一次近似（softplus の局所勾配を無視）で、エンコーダ $i$ の融合ロジットへの寄与シフトは $\delta z_i \approx \langle\Delta, W_1-W_0\rangle$、evidence 総量シフトは $\approx \langle\Delta, W_1+W_0\rangle$。**特徴を保存してあるので、softplus を通した厳密な変化も同時に計算**してある（表では `dS_exact_rel`）。一次近似は絶対値が 10〜20 倍過大に出るため、**符号の一致のみを主張**する。

### 3.3 1a（症例構成）と 1b（撮像）の分離

(grade 二値 × 年齢 3 分位) の層ごとに Δ を計算し、Kitagawa 分解する：

$$\Delta = \underbrace{\sum_k \pi^{\text{test}}_k(\mu^{\text{test}}_k-\mu^{\text{val}}_k)}_{\text{within}=\text{撮像由来}(1b)} + \underbrace{\sum_k (\pi^{\text{test}}_k-\pi^{\text{val}}_k)\mu^{\text{val}}_k}_{\text{composition}=\text{症例構成由来}(1a)}$$

**IDH ラベルは使わない**（年齢と grade のみ。既存の較正解析と同じ共変量）。両側 3 例以上の層のみ使用、test 側カバー率 0.95〜0.98。

### 3.4 検算（これが無いと符号が全部ひっくり返りうる）

行対応（row 0 = e1 か e0 か）を取り違えると $d_p$ の符号が全反転する。そこで特徴ダンプ時に：

1. **全症例**について `softplus(Wf+b)` を手計算し、モデル自身の evidence と照合 → 相対誤差 4e-4〜1e-3（GPU の TF32 由来）
2. **同じ計算を W の行を入れ替えて実行** → 誤差 3.5〜17（4 桁悪化）。行対応が一意に決まることの積極的証明
3. 1 症例について、ダンプした evidence ＋体積スケーリングから融合 α/β を再構成し、既存の `predictions.csv` と照合 → 13 ラン × val/test すべて一致

### 3.5 対象

foldA / foldB / field / vendor × 3 seed = 12 ラン、＋ **陰性対照**として random 5-fold の fold0 seed0（分布内）。計 13 ラン。

| ユニット | 中身 | val → test の変異率 | 性質 |
|---|---|---|---|
| LOSO-A | train UTSW+UPenn → test UCSF | 16.7% → 20.6% | 1a+1b |
| LOSO-B | train UCSF+UPenn → test UTSW | 11.8% → 28.4% | 1a+1b |
| field 3T | UTSW 内、1.5T 等 → 3T | 28.2% → 27.2% | **1b プローブ** |
| vendor Philips | UTSW 内、他社 → Philips | 26.0% → 35.0% | 1b プローブ（有病率は不純、後述） |
| random f0 | 全施設無作為 5-fold | 18.3% → 18.0% | **陰性対照** |

推論は eval モード、modality dropout と augmentation は無効、前処理・スライス選択は通常評価と完全に同一。体積スケーリングは evidence 段の操作なので特徴には無関係（未適用）。全ラン欠損モダリティ 0（`active_mask` は全症例 111111）。

### 4.2 解釈：ユニット間比較

**LOSO-A / LOSO-B（施設シフト）— 表現は動くが、ヘッドが読まない方向に動く**
$\Delta_{\text{null}}$ が雑音床の 2.6〜9.5 倍（最大は LOSO-A の FLAIR）。一方ヘッドが読む平面内の移動は最大 0.5σ。**特徴空間では施設がはっきり分離しているのに、その情報はヘッドの 2 方向にはほとんど乗っていない。**

これは現状の出力を壊してはいない（読まれていないので）が、裏を返せば「モデルは施設の違いを表現できているのに捨てている」ということ。以前 §14.2 で「ドメイン検知能力が育っていない（OOD でも S が −5% しか動かない）」と結論した件の、表現空間での裏付けになる。**損失にドメインの信号が一切入っていないので、ヘッドがその方向を読む理由がなかった。**

**field 3T（磁場強度だけが変わる、有病率はほぼ同じ）— 撮像差だけで criterion が動く**
$\Delta_{\text{null}}$ は床近傍（1.1〜1.5）。すなわち**撮像条件の違いは表現をあまり動かさない**。しかし動いた分はヘッドが読む方向に入る：$d_p$ が 5 エンコーダ中 4 つで同符号（負、−0.16〜−0.22）、$d_s$ は 5/5 で正。

その結果、**変異率が 28.2% → 27.2% とほぼ不変なのに、融合ロジットの平均が −0.33 ± 0.10 動く**（被験者間の標準偏差 1.94 の約 1/6）。「較正のずれ＝有病率のずれ」という前提が、**撮像条件だけでも破れる**実例である。

**vendor Philips — evidence を失うのは T2 と FLAIR だけ。T1c は無傷**
特徴から softplus を通して計算した厳密な raw evidence 変化（test/val − 1）：

| enc | raw evidence 変化 | スケール後（predictions.csv） | $S_{\text{val}} \to S_{\text{test}}$ |
|---|---|---|---|
| T1 | **+3.4%** | +2.5% | 3.38 → 3.50 |
| T2 | **−20.0%** | −20.6% | 4.64 → 3.86 |
| FLAIR | **−26.5%** | −27.1% | 4.53 → 3.51 |
| T1c | **+0.6%** | +0.2% | 8.25 → 8.30 |
| unified | −0.7% | −2.0% | 4.32 → 4.32 |

当初の予想は「T1/T2/FLAIR が大きく負、T1c は小さい」だったが、実測は **T2 と FLAIR に限定**され、T1 はむしろ微増。「半減」ではなく 2〜3 割減。unified は T1c 側（保持）に付く。

同時に T2/FLAIR は $d_p$ も +0.35 前後と正 ＝ **証拠が減るだけでなく、残った証拠も変異寄りに偏る**。

**random f0（陰性対照）— 何も検出しない**
全成分が床の 0.6〜1.2 倍、$|d_p| \le 0.10$、$|d_s| \le 0.17$。測定器として正しく振る舞っている。この対照が無ければ上記の数字はすべて疑わしい。

## 5. 結論（§2 の打ち手への翻訳）

1. **撮像由来シフト（1b）は表現をほとんど動かさない。動いた分はヘッドが読む平面に入る。**
   - vendor では **evidence 総量（$d_s$：T2 −20%、FLAIR −27%）と criterion（$d_p$ +0.35）の両方**を壊す
   - field では主に **criterion**（−0.2σ、5 エンコーダ中 4 つ同符号、有病率変化なし）
   - → **エンコーダ側介入（アフィン輝度不変な拡張、関係特徴）に投資する価値はある。ただし対象は T2 と FLAIR に限定してよい**（T1c と T1 は動いていない）
   - **期待できる効果の上限**は「vendor で失った 2〜3 割の evidence の回復 ＋ criterion 0.3σ 分の歪みの除去」。**AUC を大きく動かす話ではなく、較正と確信度の妥当性を直す話**である

2. **施設シフト（1a+1b）の主成分は $\Delta_{\text{null}}$：表現は動くがヘッドが無視している。**
   - 現状は無害。ただし「表現は施設を知っている」ので、将来ドメイン検知を実装するならここが資源になる
   - 同時に、エンコーダの不安定性の記録として残す価値がある

3. **LOSO-B の較正残差の源は、症例構成（criterion ↑）と撮像（criterion ↓）の打ち消し合いである。**
   - 切片補正は前者のみを狙う設計だったため残差が出た
   - → **エンコーダ介入は較正にも効くはず**（打ち消しの片側を消せる）

## 6. 限界（そのまま引用してよい注意事項）

- **効果量はどれも小さい**（平面内は最大 0.5σ）。3 seed の sd と同オーダーの項目もある。「シフトの主成分がどこか」は言えるが、「介入で AUC がいくつ上がるか」はこの解析からは言えない
- **vendor は本来の 1b プローブとして不純**（有病率 26% → 35%）。層別分解で「T2/FLAIR の evidence 低下は症例構成では説明できない」ことは確認済みだが、設計としては次は揃えるべき
- **一次近似は絶対値が 10〜20 倍過大**。符号の一致のみを主張している
- 雑音床は val の半分割に基づくため実際の Δ より保守的。標本サイズを揃えた補正版も併記した（補正係数 0.58〜0.67）
- 年齢 3 分位の境界は各ランの val∪test をプールした三分位。grade NA は独立の層として保持（落としていない）。UPenn は GBM コホートのため grade 4 固定（データセット定義による仮定であり、メタデータから読んだ値ではない）
- $\Delta$ は**平均の移動**のみを見ている。分散・形状の変化（共分散シフト）は測っていない

## 7. 再現方法
