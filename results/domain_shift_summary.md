## 0. 前提（3 行）

- **目的**：MRI から IDH 変異を予測する。設計思想は AUC ではなく**頑健性** — 情報が少ないときに事後分布が広がること、誤るときは自信が無いことを要件にしている
- **構造**：late fusion。6 分類器（T1 / T2 / FLAIR / T1c の各 ViT ＋ 4 シーケンス連結 unified ViT ＋ 年齢・性別 MLP）が独立に evidence を出し、和を取って Beta 分布にする（`α = Σe1 + 1`, `β = Σe0 + 1`）。融合後の単一表現は存在しない
- **評価**：3 施設（UCSF 501 / UTSW 619 / UPenn 515、変異率 18%）の施設 leave-one-site-out が主。装置ベンダー・磁場強度のシフトも別ユニットとして用意（いずれも UTSW 内、症例構成がほぼ揃うので「撮像だけが変わるプローブ」になる）

## 1. 出発点にあった問題

分布外（特に LOSO-B = UTSW を test にする条件）で**較正が壊れる**。ECE 0.162。原因の候補は 2 つあった：

- **有病率シフト**：inner-val 11.8% → test 28.4%。切片（intercept）のずれ
- **自信過剰**：evidence の総量 S が大きすぎる

温度スケーリング（spec §10）は効かなかった（T ≈ 1、ECE 0.162 → 0.160）。単調変換には切片が無いため。一方、観測された test の有病率を使う「prior オラクル」は効く（0.061）が、ラベルを見ているので deployable ではない。**この穴をどう埋めるか**が調査の起点。

## 2. 実験 A：シフトは特徴空間のどこに入っているか

ヘッドは `Linear(384→2)` なので、384 次元のうち**実質 2 方向しか読まない**。そこで val→test の平均特徴移動 Δ を 3 成分に分解した（効果量に正規化、雑音床は val の半分割ブートストラップ）：

- $u_p$（判別方向、criterion を動かす）、$u_s$（確信方向、S を動かす）、$\Delta_{null}$（ヘッドから不可視）

**結果**
- **施設シフト（LOSO）：$\Delta_{null}$ が支配的**（雑音床の 2.6〜9.5 倍）。表現は施設をはっきり分離しているのに、ヘッドが読む 2 方向にはほとんど乗らない（平面内は最大 0.5σ）
- **撮像シフト（field / vendor）：$\Delta_{null}$ は雑音床近傍**。動く分はヘッドが読む平面に入る
  - vendor：**T2 −20%、FLAIR −27% の evidence 減。T1 +3%、T1c +1%、unified −1%**（当初の「T1/T2/FLAIR が落ちる」という読みは誤りで、T1 は落ちていない）
  - field：**有病率が 28.2% → 27.2% とほぼ不変なのに融合ロジットが −0.33 動く**。5 エンコーダ中 4 つで $d_p$ が同符号
- **層別分解（grade × 年齢、ラベル不使用）**：LOSO-B では**症例構成が criterion を +0.13〜+0.42σ 押し上げ、撮像が T2/FLAIR/unified で −0.24〜−0.43σ 押し下げ、打ち消し合っている**
- 陰性対照（分布内 random fold）は全成分が雑音床（0.6〜1.2 倍）

→ **較正残差の正体**：モデルは有病率上昇に反応していたが、撮像由来の逆向きの力に打ち消されていた。

## 3. 実験 B：弱いヘッドを切ったらどうなるか

「シフト下では T2/FLAIR を不明データとして扱えばよいのでは」という提案の検証。2 通りを区別した：

- **head-off**：融合の和から項を外す（`predictions.csv` の列演算、コスト 0）
- **true-missing**：入力チャネルをゼロにして forward（unified trunk にも欠損が伝わる。訓練時の modality dropout p=0.2 と同じ経路。推論 1 回）

**結果（12 OOD ラン、ペア比較）**

| 構成 | ΔAUC | ΔECE | AUC 改善 |
|---|---|---|---|
| head-off −T2,FLAIR | −0.003 | −0.019 | 4/12 |
| **true-missing −T2,FLAIR（提案の実体）** | **−0.020** | −0.022 | **1/12** |
| head-off −T1,T2,FLAIR | +0.013 | −0.021 | 8/12 |
| （対照）−unified | −0.014 | 0.000 | 1/12 |

- **unified は欠損を肩代わりしない**：同じ落とし方どうしで true-missing は head-off より AUC −0.017（11/12 ランで悪化）
- **較正だけは改善するが、効果は LOSO-B に集中**（ECE 0.162 → 0.073）。**vendor では悪化**（0.085 → 0.106）
- **なぜかが実験 A で説明できる**：ヘッド除去は**部分的な切片補正**として働く。LOSO-B は要求 +1.09 に対し全ヘッドで +0.33、T2/FLAIR を外すと +0.52〜+0.69 に回復。vendor は $d_p$ が正（押し上げ側）なので外すと要求から遠ざかる（+0.20 → −0.07）
- → **事前予測ルール**：外すヘッドの $d_p$ の符号が必要な切片補正と逆向きなら改善、同じ向きなら悪化
- **分布内では T2/FLAIR を撮っていないことにしてもほとんど損しない**（AUC 0.931 → 0.927）

## 4. 実験 C：自信過剰仮説の棄却

2 つの補助実験。

**(C-1) 症例ごとの「分布外スコア」は使えるか**（特徴からの距離で重みを下げる案）
- 1 症例で source と shifted を見分ける AUC は **0.53〜0.63**（ほぼ偶然）。実験 A の大きなシフトは数百例の平均の話で、個別症例には落ちない
- 「どの症例を間違えるか」を当てる AUC：距離 0.55〜0.74 に対し、**モデル自身の S が 0.68〜0.77、|p̂−0.5| が 0.73〜0.82**。距離は一度も勝たず、距離＋S も S 単独を超えない
- → **症例単位のゲートに伸びしろは無い**

**(C-2) evidence 全体の定数縮小**（自信過剰を直接操作。inner-val で c を推定）

| グループ | ECE 生 | 温度 | 証拠縮小 | prior(oracle) |
|---|---|---|---|---|
| 分布外 (n=12) | 0.104 | 0.101 | **0.103** | **0.072** |
| 分布内 (n=15) | 0.044 | 0.047 | 0.047 | 0.044 |

- **効かない**（NLL も 0.452 → 0.451）。推定された c は同一ユニットの seed 間で 0.40〜1000 と不安定、2 ランは上限に張り付き（val は「もっと evidence が欲しい」と言う）
- 注：この変換は Beta の +1 が縮まないため厳密には単調でなく、AUC が動きうる（実測は最大 0.005）

## 5. 3 実験で確定したこと

**分布外の較正誤差は「確信度の水準」ではなく「切片」である。** 独立な 3 経路が同じ結論を指す：

| 操作 | 何を直す | 結果 |
|---|---|---|
| 温度スケーリング（単調、切片なし） | 確信度の傾き | 効かない 0.104 → 0.101 |
| evidence 定数縮小 | 確信度の水準 | 効かない 0.104 → 0.103 |
| prior オフセット | **切片** | **効く 0.104 → 0.072** |

そして実験 B の「ヘッド除去が LOSO-B にだけ効く」現象も、それが偶然の部分的切片補正だったことで説明がつく。

## 6. 未解決の問い（相談したいのはここ）

切片を**ラベル無しで**推定する必要がある。このプロジェクトの既存の蓄積：

| 手段 | 実績 | 限界 |
|---|---|---|
| EM（予測分布から推定） | **失敗** | 歪んだ予測分布自身に依存する循環 |
| 年齢から有病率を推定 | LOSO-A の 81〜90% を説明 | LOSO-B は 46% しか説明しない |
| 術前 grade を 1 問聞く | LOSO-B の穴を埋める | 術前は推定値（15% 誤読でも機能することは確認済み） |
| CBTRUS 外部事前確率 | 比としては機能 | 絶対値としては使えない |
| 目標施設のラベル 20〜50 例 | 切片が安定 | ラベルが要る |

**ここに実験 A が新しい項目を 1 つ足した**：上記はすべて「**症例構成（有病率）由来の切片**」を扱っている。しかし実験 A は、**撮像由来の切片ずれが別に存在する**ことを示した：

- field 3T：**有病率がほぼ不変（28.2% → 27.2%）なのに融合ロジットが −0.33 動く**
- LOSO-B：撮像成分が criterion を −0.24〜−0.43σ 押し下げ、症例構成由来の押し上げを打ち消している

**この撮像由来の成分は、年齢からも grade からも CBTRUS からも推定できない。** 残っている穴はここだと考えている。

**具体的な問い**：装置メタデータ（ベンダー・磁場強度。**推論時に既知**）から、撮像由来の切片ずれを直接推定できるか。実験 A の分解表は field/vendor で「有病率が揃った条件での純粋な撮像由来の切片ずれ」を既に測っているので、較正用の教師データとして使える可能性がある。

想定される反論・論点（相談相手に検討してほしい点）：
1. 装置の組み合わせは組合せ爆発する。未知のベンダーには外挿できないのではないか
2. field/vendor で測った切片ずれは UTSW 内部の話で、他施設に移せる保証がない
3. そもそも「撮像由来の切片ずれ」を消すべきか、それとも**エンコーダ側で発生させない**（輝度のアフィン不変な拡張。実験 A の判定では T2/FLAIR に限定してよい）方が筋か
4. 4 ユニット × 3 seed = 12 ランしかない。上記の差（ECE 0.03、AUC 0.02 程度）は seed 間ばらつきと同オーダーで、確証には追加 seed が要るのではないか

## 7. 共通の限界（どの主張にもかかる）

- 12 OOD ラン（4 ユニット × 3 seed）。ユニット内の seed 間ばらつきは AUC 0.02〜0.06 で、報告している差と同オーダー
- 実験 A の効果量は平面内で最大 0.5σ と小さい。「シフトの主成分がどこか」は言えるが「介入で AUC がいくつ上がるか」は言えない
- vendor ユニットは有病率が 26% → 35% と揃っておらず、純粋な撮像プローブとしては不純（層別分解で「T2/FLAIR の evidence 低下は症例構成では説明できない」ことは確認済み）
- ECE は 10 ビン等幅。LOSO-B の test 619 例で ±0.01 程度の揺れは想定内
- 再学習を伴う設計変更（最初から弱いヘッドを作らない等）の効果は測っていない
- 実験 A の Δ は**平均の移動**のみ。分散・共分散の変化は測っていない
